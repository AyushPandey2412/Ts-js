// DSA Survival Guide

How to Tackle Any DSA Problem

One mantra. One checklist. Every problem. Forever.

// The One Mantra
"What do I have, what do I want,
and what's the smallest step to get there?"
Ask this before touching the keyboard. Every single time. No exceptions.

// Step 3 — Write HAVE / WANT / STEP in Plain English
HAVE
What is given to me?

Write the input. Trace a simple example by hand. Don't skip this.

WANT
What must I return?

Write the exact output. What does the answer look like?

STEP
What's one small thing I can do to get closer?

Not the full solution. Just one step. Your brain can always find one step.

// Step 4 — See It in Action (Largest Sum Subarray)
Problem: Find the largest sum of any contiguous subarray
Input: [-2, 1, -3, 4, -1, 2, 1, -5, 4] → Answer: 6
INPUT
Array of numbers — some negative, some positive ✅
OUTPUT
Single number — the biggest sum ✅
SIZE
Part of array (subarray) → variable size window ✅
CONDITION
Maximum → keep updating if bigger ✅
MOVEMENT
Variable size → sliding window, reset when sum goes negative ✅
STEP
Walk through array, keep running sum. If running sum goes negative — reset to 0 (starting fresh is better). Track the biggest sum seen.

// The 3 Rules — Never Break These
01
Understand Before You Code
Trace 2 examples by hand first. If you can't explain it in one sentence — you haven't understood it yet.
02
Dumb Solution Before Smart
Always write brute force first. A working slow solution beats a blank page every single time.
03
20 Minutes Before Any Help
Struggle for 20 minutes minimum. The struggle IS the learning. AI after — never before.
