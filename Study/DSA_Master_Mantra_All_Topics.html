Topic 01 · Arrays
Arrays
"Can I solve this by walking through once and tracking one thing?"
Trigger Questions
  • Am I looking for a max/min/sum across the whole array?
  • Do I need to check every element once?
  • Is the answer a single value I build while looping?
  • Can I solve it without extra space?
Default Approach
  • Set a result variable — first element or 0
  • Loop through array — index 0 to end
  • Update result — when condition is met
  • Return result after loop ends
let result = arr[0] for(let i = 0; i < arr.length; i++) { if(arr[i] > result) result = arr[i] } return result

Topic 02 · Strings
Strings
"Is this a character frequency problem or a pattern matching problem?"
Trigger Questions
  • Do I need to count how often each character appears?
  • Am I checking if two strings are related (anagram, palindrome)?
  • Am I looking for a substring pattern?
  • Can I use the string as an array of characters?
Default Approach
  • Frequency problem? → Use HashMap to count chars
  • Palindrome? → Two pointers from both ends
  • Anagram? → Compare frequency maps of both strings
  • Substring? → Sliding window
// frequency map — most string problems let map = {} for(let ch of s) { map[ch] = (map[ch] || 0) + 1 }

Topic 03 · HashMap / HashSet
HashMap / HashSet
"Have I seen this before? Do I need to remember something for later?"
Trigger Questions
  • Do I need to find a pair that adds to a target?
  • Am I checking if something was seen before?
  • Do I need to count frequency of elements?
  • Am I grouping elements by some property?
Default Approach
  • Create empty map/set before the loop
  • For each element — check if what you NEED is in the map
  • If found → answer found, return it
  • If not found → store current element in map
let map = new Map() for(let i = 0; i < arr.length; i++) { let need = target - arr[i] if(map.has(need)) return [map.get(need), i] map.set(arr[i], i) }

Topic 04 · Two Pointers
Two Pointers
"Can I use one pointer from the left and one from the right and move them toward each other?"
Trigger Questions
  • Is the array sorted (or can I sort it)?
  • Am I looking for a pair that satisfies a condition?
  • Am I checking something from both ends (palindrome)?
  • Do I need to remove duplicates in-place?
Default Approach
  • left = 0, right = end — place pointers at both ends
  • while left < right — loop until they meet
  • Check condition — too big? move right left. Too small? move left right.
  • Found it? — return answer
let left = 0, right = arr.length - 1 while(left < right) { let sum = arr[left] + arr[right] if(sum === target) return [left, right] else if(sum < target) left++ else right-- }

Topic 05 · Sliding Window
Sliding Window
"Am I looking for the best subarray or substring? Expand right, shrink left when invalid."
Trigger Questions
  • Am I looking for a contiguous subarray/substring?
  • Is the window size fixed (k elements) or variable?
  • Am I maximizing or minimizing the window?
  • Does adding an element violate a constraint?
Default Approach
  • left = 0, track window state (sum/count/map)
  • Expand right — add arr[right] to window
  • Window invalid? — shrink from left until valid again
  • Update best result at every valid state
let left = 0, best = 0, curr = 0 for(let right = 0; right < arr.length; right++) { curr += arr[right] // expand while(curr > limit) { curr -= arr[left++] // shrink } best = Math.max(best, right - left + 1) }

Topic 06 · Stack
Stack
"Does the LAST thing I saw affect what I do with the CURRENT thing?"
Trigger Questions
  • Do I need to match opening and closing pairs?
  • Does the previous element affect the current one?
  • Am I looking for the next greater/smaller element?
  • Is there a nested structure (expressions, tags)?
Default Approach
  • Create empty stack — stack = []
  • Loop through each element
  • Peek top — does current match/complete the top?
  • Yes → pop. No → push current.
  • Empty stack at end = valid/balanced
let stack = [] for(let ch of s) { if(isOpen(ch)) stack.push(ch) else { if(stack.length === 0) return false if(!matches(stack.pop(), ch)) return false } } return stack.length === 0

Topic 07 · Queue
Queue
"Am I processing things in the order they arrived — first in, first out?"
Trigger Questions
  • Am I processing level by level (BFS)?
  • Do I need to handle things in arrival order?
  • Am I simulating a real-world queue (tasks, people)?
  • Do I need a sliding window maximum?
Default Approach
  • queue = [start] — initialize with starting element
  • while queue not empty — keep processing
  • shift() from front — process current item
  • push() to back — add next items to process
let queue = [start] while(queue.length > 0) { let curr = queue.shift() // take from front // process curr // add next items to queue queue.push(next) }

Topic 08 · Linked List
Linked List
"Use slow and fast pointers. Draw the pointers on paper before touching code."
Trigger Questions
  • Is there a cycle in the list?
  • Do I need the middle node?
  • Do I need the Nth node from the end?
  • Do I need to reverse the list?
Default Approach
  • Slow + fast pointer — slow moves 1 step, fast moves 2
  • Cycle? → they will eventually meet
  • Middle? → when fast reaches end, slow is at middle
  • Reverse? → prev, curr, next — rewire one by one
// slow & fast — cycle / middle let slow = head, fast = head while(fast && fast.next) { slow = slow.next fast = fast.next.next if(slow === fast) return true // cycle }

Topic 09 · Binary Search
Binary Search
"Is the array sorted? Can I cut the search space in half every step?"
Trigger Questions
  • Is the input sorted (or can I think of it as sorted)?
  • Am I searching for a specific value or position?
  • Am I finding first/last occurrence of something?
  • Can I eliminate half the possibilities each step?
Default Approach
  • left = 0, right = end
  • mid = Math.floor((left+right)/2)
  • Found? → return mid
  • Too small? → left = mid + 1
  • Too big? → right = mid - 1
let left = 0, right = arr.length - 1 while(left <= right) { let mid = Math.floor((left + right) / 2) if(arr[mid] === target) return mid else if(arr[mid] < target) left = mid + 1 else right = mid - 1 } return -1

Topic 10 · Recursion
Recursion
"What's the smallest version of this problem? Solve that. Then build up."
Trigger Questions
  • Can I solve this problem if I already had the answer to a smaller version?
  • Is there a natural stopping point (base case)?
  • Am I generating all combinations or subsets?
  • Is the problem defined in terms of itself?
Default Approach
  • Define base case FIRST — when do I stop?
  • Trust the recursion — assume it works on smaller input
  • Use that result — combine smaller answer into current
  • Return the combined result
function solve(n) { // 1. base case — ALWAYS first if(n <= 0) return 0 // 2. recursive case return n + solve(n - 1) }

Topic 11 · Trees
Trees (Binary Tree / BST)
"Every tree problem = solve for left subtree + solve for right subtree + combine."
Trigger Questions
  • Do I need height/depth of the tree?
  • Do I need to visit nodes in a specific order (in/pre/post)?
  • Am I searching for a path or value?
  • Level by level? → BFS. Deep first? → DFS/recursion.
Default Approach
  • Base case — if node is null, return 0/null/false
  • Recurse left — get answer from left subtree
  • Recurse right — get answer from right subtree
  • Combine — use both results to compute current answer
function height(node) { if(!node) return 0 // base let left = height(node.left) // left let right = height(node.right) // right return 1 + Math.max(left, right) // combine }

Topic 12 · Graphs
Graphs (BFS / DFS)
"Shortest path = BFS. Explore everything = DFS. Always track visited."
Trigger Questions
  • Am I finding the SHORTEST path? → BFS
  • Am I exploring ALL paths or checking if path exists? → DFS
  • Am I counting connected components (islands)?
  • Is there a cycle in the graph?
Default Approach
  • visited = new Set() — ALWAYS track visited
  • BFS → queue, process level by level
  • DFS → recursion or stack, go deep first
  • For each neighbor — if not visited, add to queue/recurse
// BFS template let queue = [start], visited = new Set([start]) while(queue.length) { let curr = queue.shift() for(let nei of graph[curr]) { if(!visited.has(nei)) { visited.add(nei) queue.push(nei) } } }

Topic 13 · Dynamic Programming
Dynamic Programming
"Am I solving the same subproblem multiple times? Store the answer. Never compute twice."
Trigger Questions
  • Am I asked for maximum/minimum ways to do something?
  • Am I counting how many ways to reach a goal?
  • Does the answer to position i depend on previous positions?
  • Would brute force recursion repeat the same calculation?
Default Approach
  • Define dp[i] — what does this value mean?
  • Set base case — dp[0] or dp[1]
  • Write transition — how does dp[i] depend on previous?
  • Return dp[n] — the final answer
// climbing stairs — classic DP let dp = new Array(n + 1).fill(0) dp[1] = 1 dp[2] = 2 for(let i = 3; i <= n; i++) { dp[i] = dp[i-1] + dp[i-2] // transition } return dp[n]

Topic 14 · Greedy
Greedy
"What's the best local choice right now? Make it. Don't look back."
Trigger Questions
  • Can I make a locally optimal choice at each step?
  • Does sorting first reveal the right order to pick?
  • Am I maximizing profit or minimizing cost greedily?
  • Does picking the best option now never hurt the future?
Default Approach
  • Sort if needed — order often reveals the greedy choice
  • Loop through — make the best local decision each step
  • Never revisit — greedy never goes back
  • Track result — accumulate as you go
// max profit — buy low sell high let profit = 0 for(let i = 1; i < prices.length; i++) { if(prices[i] > prices[i-1]) { profit += prices[i] - prices[i-1] } } return profit

Topic 15 · Heap / Priority Queue
Heap / Priority Queue
"Do I always need the smallest or largest element instantly? Use a heap."
Trigger Questions
  • Do I need the top K largest or smallest elements?
  • Do I need instant access to the minimum or maximum?
  • Am I merging K sorted lists?
  • Do I need a running median as numbers come in?
Default Approach
  • Top K smallest? → Max heap of size K
  • Top K largest? → Min heap of size K
  • Add element — push to heap
  • Heap size > K? — pop the top (remove worst)
  • Remaining heap = your K elements
// Top K frequent — use a min heap // JS: simulate with sorted array for interviews let freq = new Map() for(let n of nums) freq.set(n, (freq.get(n)||0)+1) return [...freq.entries()] .sort((a,b) => b[1] - a[1]) .slice(0, k).map(e => e[0])
